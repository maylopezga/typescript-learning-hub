# TypeScript Learning Hub - 02-pizza

This repository is my personal project for learning TypeScript and frontend fundamentals.
It is based on a course from Scrimba, and I’ve adapted it for my own learning journey and practice.


Run just the JavaScript logic in the terminal:

```
$ node index.js
```

Run a local server:
```
$ python3 -m http.server 8000
```

then open http://localhost:8000
